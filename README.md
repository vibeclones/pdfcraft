# pdfcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [pdfcraft](https://github.com/storytold/pdfcraft), a PDF reader and editor by ArtCraft. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/pdfcraft/latest/`
- Specific version: `/pdfcraft/v<version>/`
- Version list: `/pdfcraft/versions.json`

Each version folder is the unmodified contents of upstream's `pdfcraft-web-<version>.zip` release asset, including its license files. Upstream license: . A scheduled workflow mirrors new releases.
